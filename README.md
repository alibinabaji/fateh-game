# بازی فاتح

بازی استراتژی تک‌نفره‌ی نوبتی (نسخه‌ی وب) — شما (آبی) در برابر هوش مصنوعی (قرمز).

## اجرا

کافیست فایل `index.html` را در مرورگر باز کنید. نیاز به سرور یا نصب ندارد.

## ویژگی‌ها

- تک‌نفره: بازیکن آبی در برابر هوش مصنوعی قرمز
- اعزام نیرو با ضربه/لمس و درگ
- پشتیبانی از موبایل (لمسی) و دسکتاپ
- کاملاً فارسی و راست‌چین
